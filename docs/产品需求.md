# 一、先统一认知：你要做的是哪一类 AI 客服？

> **AI 智能客服 ≠ 一个聊天框 + 大模型**

从产品形态上，AI 客服可以分为 **3 个层级**：

| 层级 | 能力               | 典型产品       |
| -- | ---------------- | ---------- |
| L1 | 问答机器人（FAQ）       | 传统机器人      |
| L2 | 知识型客服（RAG）       | 大多数“AI 客服” |
| L3 | **可执行客服（Agent）** | 真正有壁垒      |

**我的建议：**

> 👉 **直接以 L2 起步，但产品架构按 L3 设计**

---

# 二、目标客户 & 场景（这是最重要的一步）

## 1️⃣ 目标客户（B 端优先）

建议你第一阶段聚焦 **中小企业 / SaaS / 电商 / ToB 产品**：

* 有客服成本压力
* FAQ 多
* 系统相对规范（有 API）

## 2️⃣ 核心客服场景（必须能落地）

先不要贪大，**锁 4 类高频场景**：

1. **售前咨询**

   * 产品介绍
   * 价格 / 套餐
   * 功能对比

2. **售后支持**

   * 使用教程
   * 常见问题
   * 故障排查

3. **订单 / 账户查询（半自动）**

   * 订单状态
   * 账户信息
   * 发票

4. **人工兜底**

   * 转人工
   * 工单生成
   * 对话留档

# 四、核心能力拆解（这是产品壁垒）

## 1️⃣ 对话管理（不是简单 chat）

**必须具备：**

* 会话上下文管理
* 多轮对话状态机
* 用户意图识别
* fallback 策略

> 产品要点：
> **不要让模型“自由发挥”，要被你控制**

---

## 2️⃣ 知识库系统（RAG 核心）

### 产品能力

* 多知识源：

  * 文档（PDF / MD / Word）
  * FAQ
  * 网页
  * 数据库
* 知识分层：

  * 公共知识
  * 租户私有知识
  * 临时知识
* 命中策略：

  * 语义相似度
  * 关键词
  * 规则优先级

### 运营视角（非常重要）

* 命中率统计
* 未命中问题自动收集
* 一键补充知识

---

## 3️⃣ Agent 能力（决定上限）

这是你产品**未来的护城河**。

### Agent 能做什么？

* 查询订单
* 创建工单
* 重置密码
* 调用第三方 API
* 生成表单

### 产品抽象

> **“技能（Skill）” + “流程（Flow）”**

* 技能：一个 API 能力
* 流程：多个技能组合

---

## 4️⃣ 人工协同（真实企业刚需）

AI 不可能 100% 覆盖。

必须有：

* 一键转人工
* 人工接管上下文
* 人工标注 & 反馈
* AI 学习闭环

---

# 五、管理后台（很多产品死在这里）

## 必须有的后台模块

### 1. 机器人配置

* 使用哪些模型
* 温度 / token
* fallback 策略

### 2. 知识库管理

* 上传
* 分词 / 切块
* 向量重建

### 3. 对话监控

* 实时会话
* 异常告警

### 4. 数据分析（产品价值体现）

* AI 解决率
* 转人工率
* 客服成本节省

# 六、MVP 路线图（非常关键）

## 阶段 1：MVP（1–2 个月）

**目标：能卖、能用**

* Web Chat
* RAG 问答
* 知识库管理
* 转人工
* 基础统计

👉 解决 **60% FAQ**

---

## 阶段 2：增强（2–4 个月）

* 多渠道接入
* Agent API 调用
* 工单系统
* 模型路由

👉 解决 **80% 客服问题**

---

## 阶段 3：平台化（6+ 个月）

* 可视化流程
* 多 Agent
* 客服 Copilot
* 自动训练

👉 **不是客服机器人，是客服系统**
